# Changelog

## 2.1.0

- Replaced random room waves with fifteen named, scripted traversal set-pieces.
- Added catchable swing vines, grind rails, bounce pads, minecart transformations, signal motes, and goblin mobs.
- Added visible room-objective progress, objective rewards, and five measurable viewer tiers.
- Limited sponsors to one offer per floor and made every immediate effect, penalty, and duration explicit in the offer and HUD.
- Rebuilt all five boss encounters around separate mechanics; Floors 1 and 2 now use a telegraphed dozer ram/stun cycle and collectible coolant-valve battle.
- Added distinct biome scenery for ruins, foundry, burrows, transit, and hunting gardens.
- Redesigned Carl's procedural sprite with a stronger silhouette, subtler face, gear, gloves, and separated Donut sprite.

## 2.0.0

- Rebuilt the game around discrete dungeon rooms and meaningful doorway choices.
- Added achievement discovery and Bronze, Silver, and Gold loot boxes.
- Added interactive safe rooms, healing tradeoffs, and three-slot run inventories.
- Added ten combinable or contextual items, including bombs, grease, traps, flares, and hazard reversal.
- Turned Donut into an active companion with Zap, Charm, and Scout abilities.
- Added rescue routes and allied-crawler protection.
- Added audience-triggered sponsor offers with risk/reward tradeoffs.
- Added five floor rule sets, five bosses, and Floor 3 class selection.
- Reworked the presentation for a lower-resolution, limited-palette cartridge style.
- Replaced layered runtime overrides with a single data-driven game state implementation.
- Added a dependency-free single-file build and automated static/runtime smoke tests.
- Migrated legacy high scores without overwriting the Version 1 save key.

## 1.0.0

- Original one-thumb endless runner preserved at the `v1.0.0` tag.
